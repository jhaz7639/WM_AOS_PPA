# WM_AOS_PPA
This github hosts the group-level results and code supporting analysis in:
> Hazelton, Chuang, Matis, Quang, Monroe, Piguet, Ballard, & Landin-Romero, 2026. Longitudinal fixel-based analysis reveals degeneration of speech motor white matter networks in nonfluent primary progressive aphasia. (_Under review_)

## Group level statistics include

Baseline:
- Baseline clinical and speech metrics
- Baseline tract level summaries from whole-brain FDC maps
- Baseline tract x speech metric results

Longitduinal:
- Longitudinal speech metrics LME results
- Longitudinal tract level summaries from whole-brain FDC maps
- Longitudinal tract x speech metrics

## Code
Code supporting group-level statistics is in Code/

All code supporting neuroimaging analyses is based on previous pipelines. 
- See MRtrix3: **https://mrtrix.readthedocs.io/en/latest/**
- See Freesurfer: **https://surfer.nmr.mgh.harvard.edu/fswiki/FsTutorial/LongitudinalTutorial**

An interactive tool has been created to display neuroimaging results for this study and can be found here: 
**https://jhaz7639.github.io/ppa_results_viewer/**
